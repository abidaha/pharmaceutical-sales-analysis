# Pharmaceutical Sales Analysis

## Overview

This project explores pharmaceutical sales data recorded between January 2014 and October 2019. The analysis investigates differences between drug categories, changes in sales over time, seasonal patterns and unusually high-sales days.

The project was developed using Python, Pandas and Matplotlib with the aim of turning a raw pharmaceutical sales dataset into a structured exploratory data analysis. 

## Key Questions

- Which drug categories had the highest overall sales?
- How did total pharmaceutical sales change over time?
- How did individual drug categories change between years?
- Do sales show seasonal patterns?
- How much does each drug category contribute to total sales?
- Which drug categories contributed most to unusually high-sales days?

## Key Findings

- N02BE consistently recorded the highest sales and accounted for almost half of total recorded sales.
- Overall sales increased between 2014 and 2016, declined in 2017 and increased again in 2018.
- N02BE and R03 showed noticeable seasonal variation, with sales generally decreasing during the summer and increasing again during the colder months.
- R06 showed a different seasonal pattern from most of the other categories.
- The 10 highest-sales days were largely driven by increased N02BE sales, with R03 also contributing substantially.

## Tools & Technologies 

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The analysis uses the Pharmaceutical Sales Daily dataset from Kaggle: [Pharmaceutical Dateset](https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data).

The raw dataset is not included in this repository.

## Limitations

The dataset only covers part of 2019, so comparisons between 2019 and complete years should be treated with caution. The analysis identifies patterns in the data but does not establish the causes behind those patterns.
